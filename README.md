# JagaRaksaFirstSubmit
Portal Aspirasi &amp; Pengaduan Fasilitas Publik  
-
Tech stack: HTML, CSS, PHP, MySQL, Tailwind, SQL, leaflet.js, chart.js


Cara menjalankan projek: Clone repo (https://github.com/repohunt-arch/JagaRaksaFirstSubmit.git) -> Pilih destinasi ke folder htdocs -> Buka File Manager -> Ekstrak file zip ke folder yang sama -> Jalankan XAMPP, Apache, dan MySQL -> Masukkan kode SQL ke MySQL-> Masukkan URL folder JagaRaksa ke search bar


Progress saat ini: Recoding kode yang dihasilkan oleh AI di index dan login page

Catatan: publikasi website di kemudian hari kemungkinan menggunakan Vercel.
